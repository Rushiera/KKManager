同一 guid 的多份文件——版本号 / 作者 / 文件名 / 时间全列出，判断权在你。指定这个版本＝这一份成为主库当前版本（不在主库则搬入并正名），同 guid 其余非旧版副本自动判为旧版（改名加 .old 段并移入缓存库，游戏不再读它们）——点了就生效，用换用此版本可再换回来；旧版行还可用正名搬入主库去掉 .old 段（主库已无该 mod 时）。打开时待确认的组排在上、已确认的沉底（本页内不再重排——处理完的那组停在原处，底部状态栏给结果）。整行点击＝该行的操作（非旧版即指定这个版本，旧版即换用 / 正名）——操作可逆，点错再点另一份即可；查看引用关系＝在本窗口之上叠一层打开这个 mod（看哪些卡片在用它）——不离开这里，关掉上层即回到本窗口原位。guid 行最右侧＝引用这个 mod 的卡片缩略图（前三张——点缩略图或「查看更多」看全部，同样是叠层窗口）。文件名下方小字＝这一份的完整文件系统路径；md5＝内容指纹（只算有重复的 mod，算过就留档、不再重算）——同一 guid 各份 md5 不同、或创建 / 修改时间不同、且这组还没挑过版本时，对应格标红块提醒你先看清再选（时间标红到段：年月日不同 → 整串标红；只有时分秒不同 → 只标红时分秒）；已挑过的组不标红。
