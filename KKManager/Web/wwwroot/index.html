待办清单
软件认为需要你处理的事 + 你自己记的事，分三支。库被判为离线（地址不存在，或库里一个东西都没有）时这里会出现一条——把它的路径改成备注写清东西放哪了，也可以直接上线或彻底删除数据（手动设为离线的库不在这里出现）。下面输入框可以自己新建一条（纯文本）；在卡片的「引用明细」里点加待办，可以给那张卡挂一条。
插件清单
插件库（BepInEx）下解析出的插件——GUID / 名称 / 版本 / 文件 / 进程过滤 / 依赖，全部只读自 dll 元数据，不改动任何文件。一个 dll 可含多项插件（如 KKAPI.dll 三项）。
加待办
给这张卡挂一条待办——登记后在「待办清单」的卡片分支里能看到，处理完就地关闭。
