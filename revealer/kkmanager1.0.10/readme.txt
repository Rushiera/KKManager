KK Manager by Rushiera —— 发布版 1.0.10
======================================================================

【本版更新】（发布版 1.0.10 · 对应编译版 0.21.1）
  · 卡片分析新增「时间轴轨道（只读）」——场景卡的轨道组树（对象 → 部位 → 子部位）+ 关键帧
    画布 + 游标：鼠标移到哪就显示那一刻命中的轨道与值；静态轨道默认折叠，一键展开
  · mod 清单新增三列引用计数——引用的角色卡 / 服装卡 / 场景卡张数（表头点击升降序）
  · unity3d 大条目加扫描闸门——条目解压后大于 200MB 时，悬停只提示，双击该条目行才开始解析
  · 扫描提速——分片库常驻（不再合并）· 增量复扫约 1.6 秒 · 进度刷新粒度 ×10 ·
    时间轴读取约快 35%
  · 修复：点「扫描主要」在分片库上锁冲突导致整体退出（先导段卡死）
  · 扫描主要库先导段——开扫先读人物卡主库本目录（不含子文件夹），面板自动切到卡片页签并选中
    该库根，文件名与卡片原图立刻可见，其余扫描随后补齐；有缩略图后自动换回缩略图
  · 插件清单升级——移到页签第四位；单插件「插件分析」窗（程序集元数据 + 中文说明 +
    配置文件全量分节 / 配置项 / 作者注释 + 上次启动实况）；行首圆点 = 上次启动实况
    （蓝 已加载 / 黄 进程过滤跳过 / 红 日志有错误 / 灰 未提及）；配置文件改带框标签；
    有配置文件的排最上
  · 插件配置值可直接改——插件分析窗「当前值」按类型给控件（开关 / 枚举下拉 · 数字框 ·
    文本框），改动行标黄并计数；点「确认」有改动先问保存（回车确认），保存走编辑授权闸门 +
    插件库根白名单，未授权不改文件；写回只改目标键那一行的值（注释 / 空行 / 顺序 / 行尾不变）
  · 扫描配置窗取消步骤排序（顺序固定、只读展示）；「扫描主要」连带扫插件库（dll 元数据 + 配置文件）
  · 插件库根不再预置只读（锁定与其余形态不变）
  · 卡片排序新增「按缺失」——缺 mod 的卡片排前面（黑 → 灰 → 黄 → 绿，同级按游戏内顺序）
  · 命令行同步：新增 `plugin-config`；`cards --order` 增 `miss`；`plugins` 增 `--unnoted`；
    `card-timeline` 增 `tracks`

【做什么】
  把「这张卡用了哪些 mod / 缺哪个 / 对应本地哪个文件」从人肉比对变成可查询的数据库。
  卡片（.png 人物卡 / 服装卡）与 mod（.zipmod）的关联按 mod 内部标识（guid）判定——
  mod 文件被改名也不影响关联，文件名只作给人看的线索。

【怎么用】
  1. 双击 KMR.exe —— 面板会在浏览器自动打开（默认 http://127.0.0.1:8539）
  2. 第一次使用：点顶部「库根设置」→ 设置游戏根目录（Koikatsu 安装目录）→ 保存
     （mod 主库 / 缓存库 / 卡片库根会按游戏根自动填入，均为锁定行）
  3. 点「扫描 mod 库」「扫描卡片库」——首扫较慢（本机 1 万个 mod 约 1 分钟量级）
  4. 之后在卡片列表 / mod 列表 / 缺失清单 / 统计卡之间查看关联与缺失

  关于扫描范围：
    · 库根由你自己添加与掌管，软件不自动遍历游戏根下的全部目录
    · 扫描范围 = 你添加的文件夹地址；不需要的目录不要加
    · 卡片库根可加多条（附加库）；mod 侧新增的库根默认是「冷冻库」（只读归档）

【数据在哪】
  data\kkmanager.db —— 本软件自己的数据库，与游戏文件无关（首次运行自动创建）
  想回到初始状态：双击「清空所有数据.bat」（两次确认；不备份，删掉恢复不了）

【运行要求】
  Windows 10 / 11 64 位 · 无需安装 .NET 运行时（运行时与全部依赖已随本程序打包）
  首次启动需解出原生库，稍慢属正常

【注意】
  · 本程序只读卡片与 mod 文件——不会改动它们（卡片编辑需在面板内单独授权后才可用）
  · 不下载 mod——缺失项只做定位提示
  · 本版本为发布版，内容冻结：升级请整包替换，不要单独替换其中文件
