KK Manager by Rushiera —— 发布版 1.0.12
======================================================================

【本版更新】（发布版 1.0.12 · Go 全量重写 · 语义基线 C# 0.21.9）
  · 程序换成 Go 全量重写版（kkgo.exe）——功能面与上一版等价：面板端点、
    命令行全集、扫描链与卡片整理链都逐条与 C# 参照实现对拍一致
  · 单文件从 193 MB 降到 13 MB；冷启动从数秒（单文件解包）降到 1 秒内
  · 免运行时——单个 exe 自带全部依赖，不需要 .NET，也没有解包步骤
  · 数据目录完全兼容：data\kkmanager.db 与分片库沿用同一套表结构与布局，
    上一版扫过的库可直接打开，不用重建（首次启动不会重建库）
  · 双击 kkgo.exe 即起面板（默认 http://127.0.0.1:8539），用法与上一版一致
  · 本版起 C# 旧程序（KMR.exe）冻结，不再更新

【做什么】
  把「这张卡用了哪些 mod / 缺哪个 / 对应本地哪个文件」从人肉比对变成可查询的数据库。
  卡片（.png 人物卡 / 服装卡）与 mod（.zipmod）的关联按 mod 内部标识（guid）判定——
  mod 文件被改名也不影响关联，文件名只作给人看的线索。

【怎么用】
  1. 双击 kkgo.exe —— 面板会在浏览器自动打开（默认 http://127.0.0.1:8539）
  2. 第一次使用：点顶部「库根设置」→ 设置游戏根目录（Koikatsu 安装目录）→ 保存
     （mod 主库 / 缓存库 / 卡片库根会按游戏根自动填入，均为锁定行）
  3. 点「扫描 mod 库」「扫描卡片库」——首扫较慢（本机 1 万个 mod 约 1 分钟量级）
  4. 之后在卡片列表 / mod 列表 / 缺失清单 / 统计卡之间查看关联与缺失

  关于扫描范围：
    · 库根由你自己添加与掌管，软件不自动遍历游戏根下的全部目录
    · 扫描范围 = 你添加的文件夹地址；不需要的目录不要加
    · 卡片库根可加多条（附加库）；mod 侧新增的库根默认是「冷冻库」（只读归档）

【从上一版升上来】
  · 整包替换即可：把新目录里的 kkgo.exe 放到原目录（与 data\ 同级），旧 KMR.exe 可保留作回退
  · data\ 目录不动——库文件与库根配置全部沿用
  · 「清空所有数据.bat」与新程序同级（它按自身目录找 data\）

【数据在哪】
  data\kkmanager.db —— 本软件自己的数据库，与游戏文件无关（首次运行自动创建）
  想回到初始状态：双击「清空所有数据.bat」（两次确认；不备份，删掉恢复不了）

【运行要求】
  Windows 10 / 11 64 位 · 免安装单文件（无外部依赖，不需要 .NET 运行时）

【注意】
  · 本程序只读卡片与 mod 文件——不会改动它们（卡片编辑需在面板内单独授权后才可用）
  · 不下载 mod——缺失项只做定位提示
  · 本版本为发布版，内容冻结：升级请整包替换，不要单独替换其中文件
