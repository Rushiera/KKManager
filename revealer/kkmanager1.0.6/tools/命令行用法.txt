KK Manager by Rushiera —— 命令行用法（发布版 1.0.6）
======================================================================

  面板是主要用法（双击 KMR.exe）。本文件列出命令行通道，供批量处理 / 排查使用。
  命令在 KMR.exe 所在目录打开命令行执行，例如：KMR.exe roots-list

  modinfo   <zipmod>                    解析单个 zipmod 的 manifest
  cardinfo  <card.png>                  解析单张卡片的声明区
  card-structure <card.png>             卡片文件结构（PNG 块表 + 图片区 / 数据区划分）
  card-detail <card.png>                卡片数据区明细（部件 / 声明区 / 内嵌贴图）
  card-params <file|dir>                读人物卡的姓 / 名 / 爱称 / 性格 + 敏感带 + 五项是否接受
  card-edit <file> --last --first --nick --personality [--weak-point N] [--denial 键=yes|no] [--archive]
                                        编辑人物卡四项 + 敏感带 + 五项是否接受（需编辑授权）
  thumb     <card.png> <out.jpg>        导出缩略图
  scan-mods [目录...]                   扫描 mod 库（无目录则用已配置的库根）
  scan-cards [目录...]                  扫描卡片库
  scan-main                             扫描主要库（预置条目——mod 主库 + 缓存库 + female / coordinate / Studio）
  scan-extra                            扫描追加库（使用者添加的库根——mod 冷冻库 + 卡片附加库；离线库跳过）
  stats                                 库统计：四色（绿 / 黄 / 红 / 灰）+ 就绪卡数
  authors                               作者清单（按 mod 数量倒序）
  dup                                   重复副本组（同 guid 多份文件——含路径 / 创建与修改时间 / MD5 + 引用卡片数与前三张卡片名）
  composition <guid> [--force] [--text] 查看某 mod 的组成（条目清单 / 目录聚合 / 文本条目）
  u3d       <zipmod> [--tex <目录>]     列出容器内 unity3d 包中的贴图
  u3d-db    <guid> <条目路径> [--force] 解析 unity3d 条目并落档
  keep-version <guid> <文件路径>        指定这个版本（同 guid 其余副本判旧版入缓存库）
  mark-old  <guid> <文件路径>           把该副本判为旧版
  swap      <guid> <文件路径>           与主库当前版本完全互换
  promote   <guid> <文件路径>           把旧版搬入主库并正名
  sort plan [目录...]                   生成「按作者整理」计划（无目录 = 全部可整理的 mod 库根；平铺 + 作者文件夹 + 冲突检测）
  sort show                             读整理计划表（做一次快照核对——已在快照位置的行标 √）
  sort exec --yes                       执行整理计划（逐条搬运 + 完成后清空目录；--yes 表示已关游戏）
  roots-list                            列出已配置的库根
  roots-add <mods|cards> <级别> <路径> [含子目录|仅本目录] [只读]
  roots-clear <mods|cards|all>          清空库根配置
  set-game-root <路径>                  设置游戏根
  serve [--port 8539] [--open]          启动本地面板

  通用: --db <路径>（默认 exe 目录下 data\kkmanager.db）· --force 全量重扫
  级别: 1=主库（游戏读取）· 2=缓存库（可一键搬入主库）· 3=冷冻库（只读）
