KK Manager by Rushiera —— 发布版 1.0.14
======================================================================

【本版更新】（发布版 1.0.14 · Go 实现 · 语义基线 C# 0.21.9）
  · 主程序恢复产品名——包内文件从 kkgo.exe 改回 KMR.exe（同一个 Go 程序，
    双击即用）；C# 旧程序已冻结并归档到 raw/dist-slots/，只作对拍基准
  · kkc 整理库改为独立开关——新增「kkc 接入」开关（默认关）。开 = 临时把
    kkc 卡片 / mod 纳入统计与列表；关 = 完全不参与，库根设置里也不再出现
    kkc 条目；数据始终共用同一个数据库
  · 面板写面点通——库根设置保存真正落盘（回执给 roots + warnings）；
    卡片编辑留档可在「寻找旧版」列出；彻底删除库根会同时清掉库记录；
    mod 反查卡片弹窗修好（此前显示「没有卡片引用」）
  · 卡片列表「按作者整理 / 索引」——索引导入把数据版本 / UAR 块数带入读面，
    cards 命令新增 --wide 看这三列
  · 重复副本改按主库口径——只统计游戏实际读取的 mods 里的重复，组内仍列
    缓存 / 冷冻库的副本供判断（本机 390 组 → 23 组）
  · 缺失清单改为一次批量取数，打开更快
  · 冲突处理回执会说明「为什么这一份没判旧」（文件被游戏占用等）

【做什么】
  把「这张卡用了哪些 mod / 缺哪个 / 对应本地哪个文件」从人肉比对变成可查询的数据库。
  卡片（.png 人物卡 / 服装卡）与 mod（.zipmod）的关联按 mod 内部标识（guid）判定——
  mod 文件被改名也不影响关联，文件名只作给人看的线索。

【怎么用】
  1. 双击 KMR.exe —— 面板会在浏览器自动打开（默认 http://127.0.0.1:8539）
  2. 第一次使用：点顶部「库根设置」→ 设置游戏根目录（Koikatsu 安装目录）→ 保存
     （mod 主库 / 缓存库 / 卡片库根会按游戏根自动填入，均为锁定行）
  3. 点「扫描主要」做首次全量扫描（预置库根 + 连带的插件库一起扫）；
     自己添加的库根用「追加库扫描」——首扫较慢（本机 1 万个 mod 约 1 分钟量级）
  4. 之后在卡片列表 / mod 列表 / 缺失清单 / 统计卡之间查看关联与缺失

  关于扫描范围：
    · 库根由你自己添加与掌管，软件不自动遍历游戏根下的全部目录
    · 扫描范围 = 你添加的文件夹地址；不需要的目录不要加
    · 卡片库根可加多条（附加库）；mod 侧新增的库根默认是「冷冻库」（只读归档）

  关于 kkc 整理库（可选）：
    · 面板「库根设置」里有独立的「kkc 接入」开关，默认关
    · 需要把整理库里的卡片 / mod 也算进缺失统计时再打开；平时不用管

【从上一版升上来】
  · 整包替换即可：把新目录里的 KMR.exe 放到原目录（与 data\ 同级）；
    上一版包名是 kkgo.exe，两者是同一个程序，替换后删掉旧的即可
  · data\ 目录不动——库文件与库根配置全部沿用
  · 「清空所有数据.bat」与新程序同级（它按自身目录找 data\）

【数据在哪】
  data\kkmanager.db —— 本软件自己的数据库，与游戏文件无关（首次运行自动创建）
  想回到初始状态：双击「清空所有数据.bat」（两次确认；不备份，删掉恢复不了）

【运行要求】
  Windows 10 / 11 64 位 · 免安装单文件（无外部依赖，不需要 .NET 运行时）

【注意】
  · 本程序只读卡片与 mod 文件——不会改动它们（卡片编辑需在面板内单独授权后才可用）
  · 不下载 mod——缺失项只做定位提示
  · 本版本为发布版，内容冻结：升级请整包替换，不要单独替换其中文件
