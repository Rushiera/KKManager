# KK Manager by Rushiera — 功能更新史

> 定位：**立项以来的重大功能更新汇总**——回答「这个软件从最早到现在，长出了哪些能力」。
> 粒度：只记**功能级变化**（新增能力 / 行为口径变更 / 影响使用的修复）；内部重构、并发留档、自检记录不入本表——逐版本明细 → `ccbp:Project/KKManager/CHANGELOG.md`。
> 口径：按**编译版号**（0.1 → 0.18.23，2026-09-26 → 09-27）记主线；面客的**发布版号**（1.0.0 → 1.0.6）与编译版对应关系见 §七，逐版台账 → `RELEASE.md` §八。
> 维护：与 `README.md`「版本更新记录」段同源——每次发布后在此追加对应条目。

**一句话**：把「这张卡用了哪些 mod / 缺哪个 / 对应本地哪个文件」从人肉比对变成可查询的数据库；在此之上支持卡片字段编辑、mod 库按作者整理、unity3d 内嵌贴图查看。

## 一、立项与侦察（v0.1 – v0.3 · 2026-09-26）

- **v0.1 立项**：定位 / 边界 / 判据落档。侦察实证 zipmod 就是 zip 容器（内含 `manifest.xml` + `abdata/**`）；**manifest 的 `guid` 与文件名无关**——重命名鲁棒性的解法锚点。
- **v0.2 卡片声明区 + zipmod 索引**：卡片数据区内含 Sideloader 声明区（UAR 块），记 `ModID`，**ModID = zipmod 的 manifest guid**；卡片**从不记录文件名**——「文件名不可作关联依据」由此实证（7 例中 2 例不一致）。同时取得缺失场景的天然样本。
- **v0.3 库根摸底 + 形态拍板**：本机实况——mod 库 **10,363 个 .zipmod · 125 GB**，卡片库 **12,438 张 .png · 50 GB**。形态定为：**单个 exe + 一键启动包 + 本地面板**（自包含发布，不要求目标机装 .NET 运行时）；缩略图从卡片图片区截取后存库。

## 二、从零到可用（v0.4 – v0.5）

- **v0.4 解析内核 + 落库 + 本地面板**：卡片 / zipmod 解析器 · **增量扫描**（size + mtime 未变即跳过）· **缩略图**（图片区截取 → 缩放重压 → 存库）· SQLite 落库（分批提交，中断只丢最后一批）· 本地 Kestrel 面板骨架（库根设置 / 扫描进度 / 统计卡 / 卡片网格 / mod 列表 / 缺失清单）· 发布物 = 100 MB 自包含单文件 + 双击启动。
- **v0.5 分级库模型 + 四色 + 反查搬运**：mod 分 **1 主库 / 2 缓存库 / 3 冷冻库**（扫描顺序强制 1→2→3）；卡片**就绪判据** = 引用的 mod 全部落在主库；卡片**四色边框**（绿=全在主库 · 黄=仅缓存库 · 灰=仅冷冻库 · 红=有缺失）；点徽标 → **反查引用明细** → 勾选搬运（缓存库→主库 = 移动，冷冻库→主库 = 复制、源保留）。

## 三、面板成型（v0.6 – v0.12 · 09-26 → 09-27）

- **v0.7 卡片表达改版 + 库根模型定版**：卡片边框色表达级别 + 悬停放大与四色计数 + 点卡片进引用明细；库根按游戏根地址**派生 4 条级别 1**（mods / female / coordinate / Studio）。
- **v0.8 引用反查贯通 + 文件定位**：mod 列表 / 缺失清单 / 引用明细三处行点击 → **「引用卡片」弹窗**（缩略图网格 + 四色边框，可加载更多）；明细里的 zipmod 文件名可点 → **资源管理器打开并选中**该文件；卡片库级别 1 置顶、文件夹分栏跨行。
- **v0.9 使用面补齐**：库根行「**浏览…**」（系统文件夹选择框）· 引用明细加**卡片信息区**与按级别分组折叠 · 卡片 / mod / 引用卡片列表**去掉条数上限**（分页退役）· 缺失清单加载失败出声。
- **v0.10 稳定性与自主化**：修面板**并发 500**（请求串行门 + 错误体回传）· **库根增删改全部归使用者**（游戏根降级为推荐模板，不再反向覆盖配置）· 明确**不做全库盲扫**（扫描范围 = 自己添加的文件夹地址）· 面板右上角**显示版本号**（版本自证）。
- **v0.11 预置主库锁定**：`<游戏根>\mods` 与卡片 female / coordinate / Studio 四条**不可改路径、不可删**（被拒的改动出声）；自己添加的条目不受影响 · 浏览框可见性加固 · 调试双槽启动（A/B 交替、前端 F5 即刷新）。
- **v0.12 前端体验轮**：卡片库**拖动排序**（行序 = 配置序）· 文件夹视图**折叠**（每个库只占一排）· 扫描进度改**右上角悬浮窗** · **记忆**上次选中的库与文件夹 · 卡片网格与 mod 列表**分块渲染**（千级列表不再一次铺满）。

## 四、批量整理（v0.14 – v0.16）

- **v0.14 未引用 mod 一键移到缓存库**：统计卡「未引用 mod」点入 → 列出全部未被任何卡片引用的 mod → 全选 / 分批搬运（只搬**主库**副本，游戏将不再加载；随时可搬回）；服务端**逐条复核**，仍被引用的跳过并出声。
- **v0.15 搬运改后台任务**：逐项进度、**页面关掉也继续跑**、重开可见进度与结果、可停止（实测单文件搬移固定 ~3 秒，同步跑必然表现为「卡住」）；「未被引用的 mod」口径收窄为**主库中未被引用**并**按文件大小从大到小**先处理大的。
  - **v0.15.1 库根设置强绑定**：游戏根地址 = 4 条级别 1 的**唯一来源**，选定即自动填入；**未设置时按钮持续闪红**提示先设置；「填入推荐库根」改为「浏览…」。
  - **工具**：`清空所有数据.bat`（两道确认，回到初始状态）。
- **v0.16 重复副本与旧版机制**：统计卡「重复副本」点入 → 同 guid 的多份文件按组列出（级别 / 库根 / 文件名 / 大小 / 改于 / **manifest 版本号 / 作者**，打开时实时读）· **判为旧版**（改名加 `.old` 段并移入缓存库，落新旧关系记录）· **换用此版本**（旧版与主库当前版本完全互换，主库全程不空）· **正名搬入主库**；mod 列表新增「旧版」列。
  - **v0.16.1 mod 列表排序与作者筛选**：「被引用」「大小」表头点击排序（▲ / ▼）· 作者列**模糊筛选**（多选 + 只看选中）· 新增「版本」「大小」两列。
  - **v0.16.2 表与索引**：mod 表改定宽布局（超长列省略号 + 悬停看全文）· 作者清单改**库侧聚合索引**（本机 853 位作者，按发布数量倒序）· 列表分块渲染。

- **v0.17.2 缺失清单提速**：读取加缓存、扫描结束即失效 + 统计卡「红 · 缺失」一键跳转。

## 六、编辑与贴图（v0.18.0 – v0.18.15）

- **v0.18.0 unity3d 分析落地**：mod 组成里的 `.unity3d` 条目 → **悬停**出内部贴图浮层（首次「解析中…」，之后秒开）→ **点击条目**固定浮层 → 浮层内点缩略图**放大**；已解析过的条目**标蓝**；贴图清单按需建档（按 zipmod 大小 / 修改时间判失效，未变直接复用）。
- **v0.18.1 修解析失败**：部分 mod 报「SerializedFile 头部异常」——根因是块表 flags 字节序读错（改按大端读），修后该类 mod 正常出图。
- **v0.18.3 贴图解码扩容**：新增 **BC7（格式 25）全 8 模式解码**（与本机参考解码器逐字节一致，269/269）· 修**超大包解析**（实测 1.42 GB / 5,409 块可解析）· 解析失败**出声**（此前只在浮层可见、服务端日志无痕）。
- **v0.18.2 卡片编辑落地**：可改**姓 / 名 / 爱称 / 性格**（下拉 40 项，含额外 mod 的性格 83）；**最小改动**写回——只改被编辑的字节（实测等长改动整文件仅 1 字节不同），文件创建 / 修改 / 访问时间与属性**全部还原**；**原版自动留档**在软件内部，配「寻找旧版」可列可定位。
- **v0.18.14 卡片编辑扩展**：新增**「敏感带」**（嘴唇 / 胸部 / 无）+ 五项**「是否接受」**（接吻 / 爱抚 / 肛门 / 按摩 / 不戴套）——均为等长替换（实测三项合计整文件仅 3 字节不同、字节增量 0）；表外取值不猜名，按「未收录（值 N）」呈现。
- **v0.18.4 更名**：项目更名 **KK Manager by Rushiera**，主程序 **`KMR.exe`**（显示名与标识符分离；历史条目按当时名称保留）。
- **v0.18.5 发布体系建立**：新增 `revealer/` 发布区——发布规范（`RELEASE.md`）+ 发布技能（`SKILL.md`）；发布版**独立编号、生成即冻结、只能由编译版转换、更新即全量重发 +1**；调试专用功能不入包；依赖全自包含（面客机器无需装 .NET）。**首个发布版 1.0.0**——双击 exe 即起面板。
- **v0.18.6 首次使用修复**：换游戏根后点「更新本库」**自动先保存再扫描**（不再报「库根不在配置里」）；换游戏根时预置条目按新根**重派生**（不再多出指向默认根的死路径）；报错改为可执行中文说明 + 保存成功打印回执。

- **重复副本体验线**：
  - **v0.18.10 整行点击 + 查看引用关系**——点整行即完成该行操作（按钮保留）；「查看引用关系」跳到该 zipmod 的 mod 清单并打开。
  - **v0.18.16 改叠层打开**——在本窗口**之上叠一层**打开 mod 窗口，页签不跳、下层不关，关掉即回原处。
  - **v0.18.17 组行缩略图**——每个 guid 行**最右侧**显示引用它的**卡片前三张** + 「查看更多 (N)」，点即叠层打开引用卡片窗口。
  - **v0.18.18 行更紧凑 + 时间标红到段**——年月日不同整串标红；只有时分秒不同则**只标红时分秒**。
  - **v0.18.19 打开提速**——引用的卡片由「每组重算一遍全库」改为**一次批量查询**（本机实测改前 6.4 秒）。

- **v0.18.11 扫描清扫**：磁盘上已删除的卡片 / mod 记录随扫描一并清理并出声（离线库内容保留）。
