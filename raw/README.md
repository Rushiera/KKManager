## C# 参照为什么在这里

2026-11-17 旧结构清扫：仓库根只留**现行实现**（`kkgo/`）与发布区（`revealer/`），C# 参照源码 / 探针 / 跑测件整棵移入本目录归档。

- **真相源仍是 git 历史**：历史形态从 `git show <commit>:KKManager/<path>` 取（移动前的路径就长这样）；移动后的路径是 `raw/KKManager-CSharp/<path>`。
- **对拍基准产物不在这里**：`../dist/KMR_B.exe`（0.21.9）留在数据区原位，只在需要重编对拍基准时才动。
- 归档原则：**只读**——不接线新需求、不改 C# 源码；Go 侧的语义基线仍以它为准（有疑义时读它，不平移）。

## 纪律

- 本目录只放「原稿级」材料（过程记录 / 一次性分析 / 外部资料摘录）；**结论与判据进 CCBP 档案**。
- 新增文件在「内容」表里登记一行（本目录无索引器，人读）。
- 与 `revealer/`（发布规范与发布包）不同：那里面客，这里面向开发者自己。
