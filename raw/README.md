## 原 C# 仓在哪

**不在本目录**——原位冻结在 `../KKManager/`（`KKManager.csproj` `<Version>` = 0.21.9，只读参照）。

理由：**单点真相源**。C# 源码只有一份，复制到 `raw/` 会形成双写、随轮漂移；需要历史形态时从 git 取（`git show <commit>:KKManager/<path>`），对拍基准产物是 `../dist/KMR_B.exe`（0.21.9）。
