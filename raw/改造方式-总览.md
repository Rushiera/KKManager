# KK Manager — Go 全量重写：整体改造方式

> 定位：本项目从 **C# 单实现（0.21.9 冻结）** 迁到 **Go 单实现（发布版 1.0.12 → 1.0.13）** 的改造方式总览。
> 读者：以后再做一次「同语义换实现」的人，或半年后的自己。
> 边界：各命令细节在源码（`kkgo/`）；进度与历史在 `ccbp:Project/KKManager/`；发布规范在 `revealer/RELEASE.md`。
> 建立：2026-11-15（1.0.13 发布轮）。

---

## 一、目标与不变量

**目标**：同语义换实现——功能面与 C# 版等价，但交付形态从「193 MB 自包含 .NET 单文件」降到「13 MB 静态 Go 单文件」，免运行时、无解包、冷启动 <1 s。

**四条不变量（换实现不能变的）**：

| # | 不变量 | 判据 |
|:--:|:--|:--|
| 1 | **数据面兼容** | 同一套表结构 / 分片布局 / 设置键——旧库 `data\kkmanager.db` 直接打开，不重建 |
| 2 | **输出契约逐行等价** | CLI 文本按行一致；面板 JSON 按形状 + 字段 + 值三层一致 |
| 3 | **写面语义不变** | 最小改动（只改必须改的字节）· 写前留档 · 授权闸门在服务端 |
| 4 | **发布形态** | 单文件 / 免运行时 / `data\` 与 exe 同级 / 双击即起面板 |

**一条方法总纲**：**抄判据与顺序，不抄代码**——C# 的类结构不照搬，按 Go 的包边界重排；但每一处行为口径（输出行、字段名、错误码、退出码）逐条对齐。

## 二、分层（一个薄壳入口 + 三个内层）

```
kkgo/
  main.go            CLI 薄壳：参数解析（53 条命令 switch）+ 输出打印
  main_cardsort.go   card-sort 命令族（11 子命令）
  main_u3dtypes.go   u3d-types（裸 unity3d 包对象类型分布）
  internal/core/     业务：解析核 / 扫描链 / 整理链 / 写面 / 跨库编排
  internal/store/    SQLite：主库 + 分片库 + 迁移 + 查询 + 预热
  internal/web/      net/http 面板（路由表 + 端点分文件 + embed 前端）
  tools/compare/     对拍脚本（compare.py / panel.py）
```

**分工判据**：

| 层 | 只做 | 不做 |
|:--|:--|:--|
| `main` | 取参数 → 调 core → 打印 | 任何业务判定、任何 SQL |
| `core` | 业务规则 / 解析 / 编排 | 直接持有 DB 连接（走 store） |
| `store` | SQL + 事务 + 迁移 | 业务语义 |
| `web` | HTTP 路由 + JSON 装配 | 复制 core 的实现（薄壳化） |

**薄壳化纪律**：同一能力只允许一处实现。1.0.13 把 `composition` / `modfiles` 的 main 侧双实现删掉，改调 core——判据是 `compare.py composition` 18/18 逐行一致。

## 四、对拍方法（本项目的验收核心）

**三条腿，缺一条就是「跑过了」**：

| 腿 | 手段 | 判据示例 |
|:--|:--|:--|
| **命令输出逐行** | `compare.py <命令>`（两侧同参跑，逐行 diff） | `all` 29 项 0 差异 |
| **面板 JSON 形状** | `panel.py`（同端点两侧取 JSON，按形状 / 字段 / 值三层比） | 34 → 38 项全绿 |
| **数据面字段级** | 两侧写同一临时库后直读 SQLite 比行 | 43/43 行全同 · `card_mod` 83,666 行一致 |

**样本纪律**：

- **真库只读**——一切功能验证用 CatTemp 临时库 / 干净目录；真库 `dist/data` 全程只读。
- **样本要能复现**：每个对拍用例自带输入（真 zipmod / 真卡片 / 合成索引），脚本可复跑。
- **差异分三类**：形状（键缺 / 多）→ 字段（命名）→ 值（格式）。**先对齐形状，再对齐字段，最后才调值**——顺序反了会反复返工。

**对齐细节的典型坑**：

- 千分位（`N0`）与小数（`0.###`）要手写实现（InvariantGlobalization 口径）；
- JSON 键命名策略（小写 camel vs PascalCase）在不同端点不同源——**照抄现状，不统一**；
- 编码（GBK 936 需注册代码页 provider；Go 侧输出 UTF-8）；
- 时间戳格式（创建 / 修改 / 解析时刻各有口径）。

## 五、关键机制移植点

| # | 机制 | Go 侧做法 | 判据 |
|:--:|:--|:--|:--|
| 1 | SQLite | `modernc.org/sqlite`（纯 Go，`CGO_ENABLED=0`） | 单文件无伴随 dll |
| 2 | 模板库 | `go:embed` 内置 204 KB 空库；缺库先释放 | 新库 `user_version=2` + 25 张表 |
| 3 | 分片库 | 分片键 FNV-1a（UTF-16 码元口径）· 片数定下不裁剪 | 同实体落同片 |
| 4 | 预热 | 进程级 warm keeper：后台逐片「打开→哨兵写入→连接常驻」 | 首扫 78.1 s → 12.7 s · 退出关闭 >40 s → ~0 |
| 5 | 事务死锁 | **所有 store 方法走 `d.execer()`**（扫描事务期间单连接被 Tx 占用，直接 `d.sql` 会死等） | 扫描中并发查询不卡 |
| 6 | 增量判据 | `scan_state` 完成戳 + size/mtime 双等 | 二次扫描毫秒级 |
| 7 | 前端 | `embed` 原样内嵌 `wwwroot/index.html` | 面板与 C# 逐项一致 |
| 8 | 版本自证 | 无 PE 版本资源 → `-X main.version` + `kkgo.exe version` + `settings.version` | 三处同值 |

## 六、发布链（Go 版）

```powershell
# cwd = kkgo/
go build -trimpath -ldflags "-s -w -X main.version=<发布版号> -X main.releasePack=1" -o <CatTemp>\kkgo.exe .
```

**发布前六项核验**（`RELEASE.md` §七）：

| # | 项 | 判据 |
|:--:|:--|:--|
| 1 | 无参启动 | 无参实跑 → 起面板（不是打印用法） |
| 1b | 发布标识 | `help` / `version` 首行含「发布版（ReleasePack 编译）」 |
| 2 | 版本自证 | `kkgo.exe version` = 发布版号 + `GET /api/settings` 的 `version` |
| 3 | 依赖自包含 | 干净目录 `roots-list` 通（SQLite / embed / 前端三件自证）· 目录无 dll |
| 4 | 目录形态 | 根目录只三样：`kkgo.exe` + `清空所有数据.bat` + `readme.txt`（其余进 `tools/`） |
| 5 | 冻结核对 | 生成后不再编辑；要改 = 版号 +1 全量重发 |
| 6 | 三处同源 | `README.md` 置顶段 · `readme.txt`【本版更新】· `RELEASE.md` §八 台账末行 |

**铁律**：不在发布目录跑 exe（会生成 `data/`）；exe / zip 不入仓（走 Release 附件）。

## 七、反模式（做过一次别再做的）

1. **按文件名反推版本 / 槽位**——文件名是约定，修改时间与 PE 版本才是事实。
2. **只改一处默认值**——同一语义在启动脚本与程序里各有一份时必须同改。
3. **把「编译过」当「上线了」**——编译产物落点与运行入口是两件事。
4. **把「清单里有行」当「磁盘上有文件」**——删除要等扫描清理；离线库故意保留内容。
5. **在文档里写死会随版本改的数值**——写判据与取数方式，值指向实测记录。
6. **靠「再读一遍代码」排查性能**——先补观测位点，再谈优化。
7. **把拒绝做成静默降级**——读不到就说读不到，不回落默认值假装正常。
8. **main 侧复制 core 的实现**——两套必然漂移；薄壳化是纪律，不是优化。
9. **绕过事务包装直连 DB**——扫描期必死锁（见 §五-5）。
10. **在发布目录里跑 exe**——`data/` 会污染发布包形态，且违反冻结。

## 八、与 C# 的差异口径（哪些不照抄 / 哪些必须照抄）

| 面 | C# | Go（现行） | 口径 |
|:--|:--|:--|:--|
| 调试双槽 `_A/_B` + `启动.bat` | 有 | **无**（单 exe 单端口） | 不照抄（Go 无文件锁问题） |
| PE 版本资源 | 有（`file-version`） | **无**（`version` 命令 + `settings.version`） | 不照抄，判据改口径 |
| 条件编译 `RELEASEPACK` | `-p:ReleasePack=true` | `-X main.releasePack=1` | 机制不同、哨兵相同（漏传 = 双击只打印用法） |
| 并发模型 | 线程池 + 分片 worker | goroutine（同语义） | 实现自由，计数口径对齐 |
| CLI 输出文本 | 基准 | 逐行一致 | **必须照抄** |
| 面板 JSON 形状 | 基准 | 逐字段一致 | **必须照抄** |
| 错误码 / 退出码 | 基准 | 一致（如旧版管理失败 exit 3） | **必须照抄** |
| 数据表 / 分片 / 设置键 | 基准 | 完全一致 | **必须照抄**（旧库直接打开） |
